\section{Abstract}
Some apps have been created to meet the needs of developers. The user manual explains how to use the binaries made available to users; this section explains how to use the binaries intended for developers. They should be used only after completing the install of SW2D.

%\section{Rotation tool}
%
%\subsection{Purpose}
%This is the sw2dRotation.exe executable. This is used to rotate an existing simulation directory.
%
%\subsection{Execution}
%To run this tool :
%\begin{enumerate}
%\item Open a shell
%\item Navigate to the parent folder of the simulation folder to be rotated.
%\item Type:  \texttt{sw2dRotation.exe [folder name] [angle] [x] [y]}
%where  \texttt{angle} is the angle of rotation to be applied, and  \texttt{x} and  \texttt{y} are the coordinates of the centre of rotation. These last two parameters are optional, the default coordinates of the centre of rotation are $(0,0)$.
%\end{enumerate}
%
%\subsection{Usage}
%After execution, a directory is created in the same location as the original directory, with the same name appended with“\_rotated\_[angle]”.
%It contains the same files as the original, but those containing coordinates have been modified to reflect the rotation.
%It can be used to run simulation like other simulation folders.
