The inline code documentation is generated using Doxygen.
The procedure is the following.
\begin{itemize}
\item go to the ./doc folder. You should find the "common", the "pdf" folder (contains the present doc), "Doxygen" folder and the .doxyfile file.
\item Open a terminal
\item Type
\begin{verbatim}
doxygen doxyfile
\end{verbatim}
\item 1 new folder is created : html
\item In the /html folder, open index.htm
\end{itemize}

The html documentation can also be generated thanks to the \texttt{sw2d} command (see Section \ref{sec:sw2d-command}).
