# Contributing to SW2D

Thank you very much for your interest in SW2D. Do not hesitate to let us know your interest by [sending an email to our workgroup](mailto:sw2d-admin@inria.fr). This is the best way to stay informed of new features and/or revisions of SW2D.

---
## Issues and questions

Before raising questions, please have a look at [SW2D documentation](https://gitlab.com/sw2d-workgroup/sw2d/-/tree/main/doc/pdf) (for both users and developers).

To report an issue, feel free to use the [SW2D issue tracker](https://gitlab.com/sw2d-workgroup/sw2d/-/issues) where you can both browse former issues (open or closed) and create your own one. An "issue" may be a bug report (see below), a feature request, a partnership proposal... or a simple naive question. Please don't be shy!


### Reporting bugs
If you think you may have encountered a bug, please raise the issue identifying the bug and provide as many details as possible, including:

- descriptive title
- input files (if possible), especially  if the bug only manifests on a specific case. If input files are too large, you can provide a link.
- error report (hopefully SW2D will provide one through your shell), ideally as Markdown in your bug report text body.
- if you face compilations issues, please provide information on your Windows/Linux/MacOs distribution, compiler and dependency versions.
- let us know any context the problem started happening in with a new version, a new case, a new system, etc.

### Feature request
Implement a new numerical method, couple SW2D with new equations or build an external mesh tool: we would be more than happy to help you with new features. Feel free to open an issue for this, providing as much details as possible (including necessary input files).

## Contributing to the code
SW2D is an open source code and we are happy to welcome community contributions. If you wish to contribute to the code, please keep the following in mind:

### Resources
Check the [SW2D Developer Guide](https://gitlab.com/sw2d-workgroup/sw2d/-/blob/main/doc/pdf/sw2d_developer.pdf). This explains the developer code rules, together with most of the routines developed in the code.


### License
SW2D has an [open source license](https://gitlab.com/sw2d-workgroup/sw2d/-/blob/main/LICENSE.md). Please make sure you agree with this license before contributing. The project is intended to be fully open source to guarantee community access. If your contribution for some reason cannot be fully open source (or perhaps has a temporary embargo), [please contact us](mailto:sw2d-admin@inria.fr) before contributing.

### Conditions
Of course, contributions will be acknowledged both by the native contributor logs in GitLab, and in the [CONTRIBUTORS.md](https://gitlab.com/sw2d-workgroup/sw2d/-/blob/main/CONTRIBUTORS.md) file.
